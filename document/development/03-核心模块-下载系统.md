# 核心模块：下载系统

> 开发 Wiki 第三篇 · 下载、多段下载与安装

## 1. 模块结构

```
lib/core/download/
├── download.dart               # 模块统一出口
├── DownloadStrategyManager.dart# 按渠道选择下载策略
├── model/DownloadContext.dart  # 下载上下文
├── strategy/
│   ├── IDownloadStrategy.dart  # 策略接口
│   ├── BaseDownloadStrategy.dart
│   └── impl/                   # GitHub/Http/Vivo/Fdroid/LocalDb 各渠道策略
├── segment/
│   ├── segment_planner.dart    # 分段规划（段数/范围/Range 头）
│   ├── segment_downloader.dart # 并发分段下载（可取消/暂停）
│   └── segment_merger.dart     # 段文件合并/清理
└── exception/DownloadException.dart
```

## 2. DownloadService（任务管理）

`lib/core/service/downloadService.dart`，GetxService，负责下载任务生命周期：

- 常量：`maxConcurrentDownloads = 3`（并发上限）、`maxRetryCount = 3`。
- 入口：`download(appid, appName, version, url, fileName, ...)` 与 `downloadWithContext(...)`。
- 信号量 `DownloadSemaphore` 控制并发。
- 根据文件大小与渠道判断是否启用多段下载（`_shouldUseMultiSegment`）。
- 状态持久化到 `DownloadStatus` 表（sqflite）。

### 下载状态

`lib/http/download/DownloadStatus.dart`：

| 常量 | 含义 |
| --- | --- |
| `DOWNLOAD_ERROR` (-1) | 失败 |
| `DOWNLOAD_READY` (1) | 就绪 |
| `DOWNLOAD_LOADING` (2) | 下载中 |
| `DOWNLOAD_SUCCESS` (3) | 成功 |

## 3. 多段下载（segment/）

### SegmentPlanner

- `calcSegmentCountForSize(size)`：按大小计算段数（小文件单段、中等自适应、超大文件上限 8 段）。
- `divideSegments(...)`：划分范围并生成 `Range: bytes=a-b` 头、part 文件名。

### SegmentDownloader

- 并发下载各段，支持取消（`cancelToken`）与暂停。
- 每段独立进度，暂停后所有段 token 取消。

### SegmentMerger

- 按顺序合并 part 文件为完整文件；缺少 part 返回 false；提供 `cleanupParts`。

### 分段策略（_shouldUseMultiSegment）

- 文件足够大（超过阈值）且服务端支持 Range 时才走多段；否则回退单段下载。

## 4. 下载策略（strategy/）

`DownloadStrategyManager` 按渠道选择策略：

| 策略 | 渠道 | 说明 |
| --- | --- | --- |
| `GitHubDownloadStrategy` | github | 匹配 CPU 架构选择 APK 资产 |
| `FdroidDownloadStrategy` | fdroid | 从 F-Droid 索引取下载地址 |
| `VivoDownloadStrategy` | vivo | 解析 vivo 下载链接 |
| `HttpDownloadStrategy` | http | 直链下载 |
| `LocalDbDownloadStrategy` | local_db | 本地库直链 |

## 5. 安装管理（InstallManager）

`lib/core/service/install_manager.dart`：

- `installApk(filePath)` 返回 `(bool, InstallMethod)`。
- 优先 **Shizuku 静默安装**（`silentInstall`），未授权时回退系统安装器。
- `managePackage` / `clearAppData` / `clearCache` / `forceStop` 走 Shizuku 命令（需授权）。
- `_systemIntentChannel` 用于部分系统级调用。

## 6. APK 信息解析

- `apk_info_service.dart`：通过 Rust FFI（`parse_apk_info`）解析 APK 元数据（包名/图标/版本）。
- 下载完成后自动解析，更新真实包名/图标/应用名。

## 7. 测试覆盖

`test/segment_test.dart`、`test/segment_cancel_test.dart`：

- 合并完整性、缺失 part 返回 false、清理。
- 暂停/取消行为。
