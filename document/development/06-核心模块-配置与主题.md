# 核心模块：配置中心与主题系统

> 开发 Wiki 第六篇 · ConfigService、模块化注册、设计系统与主题

## 1. 配置中心（config/）

### ConfigService（统一门面，推荐入口）

`lib/core/config/config_service.dart`，单例，配置系统的统一门面：

| 能力 | 说明 |
| --- | --- |
| 声明式注册表 | `ConfigEntry`：key/类型/默认值/敏感/Agent 白名单/描述/分组/单位/范围/示例 |
| 模块化注册 | `ConfigModule` 抽象 + `registerModule/unregisterModule/hasModule/moduleNames`（上下线） |
| 结构化快照 | `snapshot(key)` / `snapshots()`：元数据 + 当前值合并（敏感脱敏为 `***`），`toJson()` 供 Agent 解析 |
| 统一事件总线 | `onChange` / `watch(key)` / `watchMany(keys)`：变更携带 old/new/source（user/agent/internal） |
| 读写路由 | 已桥接 `ConfigProvider` 的 key 委托 provider（theme/download/update/webdav），其余走 ConfigStore |
| 类型/范围/枚举校验 | set 时校验，失败返回结构化错误信息 |

```dart
// 写入（修改后相关功能自动生效）
await ConfigService.instance.set(ConfigKeys.themeMode, 2, source: ConfigChangeSource.agent);
// 观察（功能模块作为订阅者主动响应）
ConfigService.instance.watch(ConfigKeys.themeMode).listen((e) { ... });
// 快照（Agent list 一次拿全）
final snaps = await ConfigService.instance.snapshots();
```

**核心架构**：写入方（Agent/UI）只写配置；功能模块（ThemeController/DownloadService/代理桥接/AgentService 等）作为**配置订阅者**，监听 onChange 后主动响应——实现"配置修改 → 功能主动更新"，而非调用方直接操作功能。

### ConfigStore（统一存储访问器）

`config_store.dart`：封装 Composite 存储，敏感 key 自动路由加密存储（SecureStorage）、
类型化读写（bool/int/double/String/List）、键迁移（migrate）、统一变化事件（changes）。

### ConfigStorage（存储抽象）

`config_storage.dart`：`SharedPrefsConfigStorage`（普通）/ `SecureConfigStorage`（加密）/
`MemoryConfigStorage`（测试）/ `CompositeConfigStorage`（组合）；全部支持 `changes` 事件流与 `watch`。

### ConfigManager（旧入口，兼容保留）

`config_manager.dart`：注册 ConfigProvider、loadConfig/saveConfig/clearConfig/exportAll/importAll（备份用）。

### 内置注册表（config_registry.dart）

- `ConfigKeys` 常量：theme_config/theme_mode/download_config/update_config/webdav_config/proxy_url/agent_models/agent_selected_model_id/fdroid_sources/last_source_id/selected_channels。
- `AppCoreConfigModule`：内置配置项模块（作为 ConfigModule 范例）。
- `migrateLegacy`：存量散落 key（无前缀 prefs）自动迁移到统一存储。

### 配置备份

`config_backup.dart`：`ConfigBackupData`（configs 集合），纳入 `BackupData.extras`，
可在备份/恢复时随数据一起导出/导入。

## 2. 设计系统（core/design/）

> 遵循 Material 3 + 主题令牌，**禁止硬编码颜色/字号**。

| 文件 | 内容 |
| --- | --- |
| `design_tokens.dart` | 设计令牌统一出口 |
| `app_colors.dart` | 颜色（用 `Theme.of(context).colorScheme`，不直接用 Colors.xxx） |
| `app_typography.dart` | 字号/字重（`AppTypography.sizeLG` 等） |
| `app_spacing.dart` | 间距（`AppSpacing.allLG` / `sm` 等） |
| `app_radius.dart` | 圆角（`AppRadius.allMD`） |
| `app_shadows.dart` | 阴影 |
| `app_animations.dart` | 动画 |
| `app_dialogs.dart` | 统一对话框入口（`AppDialogs.showDialog` / `showSuccess` / `showError`） |
| `app_components.dart` | 通用组件（`AppLoading` / `AppLoadingSize` / 按钮等） |

### 核心规则（务必遵守）

1. 颜色/文字一律 `Theme.of(context).colorScheme` / `.textTheme`。
2. 确认框/提示框一律 `AppDialogs.showDialog`（危险操作 `isDangerous: true`）。
3. loading 用 `AppLoading` / `AppLoadingSize`。
4. COLR 彩色字体图标 `AliIcon` 必须用 `ColoredAliIcon` 染色（夜间模式可见）。
5. Snackbar 用 `AppDialogs.showSuccess` / `showError`。

## 3. 主题系统（theme/）

### 文件

| 文件 | 说明 |
| --- | --- |
| `theme_controller.dart` | `ThemeController`：主题模式（system/light/dark）+ 主题配置流 |
| `theme_data_builder.dart` | 从配置构建 `ThemeData`（Material 3） |
| `theme_utils.dart` | 工具函数 |
| `app_theme_config.dart` | `AppThemeMode` 枚举与 `AppThemeConfig` |

### 能力

- `AppThemeMode.system/light/dark` 切换，支持循环切换（`toggle`）。
- 自定义主色（首页"我的"提供 6 色快捷选择）。
- Android 12+ 动态取色（dynamic_color 包）由 `theme_data_builder` 集成。

### 持久化与订阅者模式

- 写入统一走 ConfigService（`setThemeMode` → `ConfigService.set(theme_mode)`），
  ThemeController 同时订阅 provider 流与 ConfigService 事件，配置变化后主动更新 Rx → UI 自动刷新。
- 启动时 `ThemeController` 加载恢复。
