# 核心模块：配置中心与主题系统

> 开发 Wiki 第六篇 · ConfigManager、设计系统与主题

## 1. 配置中心（config/）

### ConfigManager

`lib/core/config/config_manager.dart`，单例，统一的键值配置中心：

| 方法 | 说明 |
| --- | --- |
| `initialize` | 初始化并执行版本迁移 |
| `loadConfig<T>(configKey)` / `saveConfig` / `clearConfig` / `hasConfig` | 泛型配置读写 |
| `exportAll` / `exportToJson` | 导出全部配置（备份） |
| `importAll` / `importFromJson` | 导入配置（恢复） |

- 内部带版本号（`_currentVersion = 1`），升级时自动迁移。
- 配置项通过 `ConfigProvider<T>` 注册（`config_provider.dart`）。

### 内置 Provider（providers/）

| Provider | 管理内容 |
| --- | --- |
| `download_config_provider` | 下载相关配置 |
| `theme_config_provider` | 主题/配色配置 |
| `update_config_provider` | 数据源更新配置 |
| `webdav_config_provider` | WebDAV 配置（与 secure_storage 配合） |

### 配置备份

`config_backup.dart`：`ConfigBackupData`（configs 集合），纳入 `BackupData.extras`，
可在备份/恢复时随数据一起导出/导入。

## 2. 设计系统（core/design/）

> 遵循 Material 3 + 主题令牌，**禁止硬编码颜色/字号**。

| 文件 | 内容 |
| --- | --- |
| `design_tokens.dart` | 设计令牌统一出口 |
| `app_colors.dart` | 颜色（用 `Theme.of(context).colorScheme`，不直接用 Colors.xxx） |
| `app_typography.dart` | 字号/字重（`AppTypography.sizeLG` 等） |
| `app_spacing.dart` | 间距（`AppSpacing.allLG` / `sm` 等） |
| `app_radius.dart` | 圆角（`AppRadius.allMD`） |
| `app_shadows.dart` | 阴影 |
| `app_animations.dart` | 动画 |
| `app_dialogs.dart` | 统一对话框入口（`AppDialogs.showDialog` / `showSuccess` / `showError`） |
| `app_components.dart` | 通用组件（`AppLoading` / `AppLoadingSize` / 按钮等） |

### 核心规则（务必遵守）

1. 颜色/文字一律 `Theme.of(context).colorScheme` / `.textTheme`。
2. 确认框/提示框一律 `AppDialogs.showDialog`（危险操作 `isDangerous: true`）。
3. loading 用 `AppLoading` / `AppLoadingSize`。
4. COLR 彩色字体图标 `AliIcon` 必须用 `ColoredAliIcon` 染色（夜间模式可见）。
5. Snackbar 用 `AppDialogs.showSuccess` / `showError`。

## 3. 主题系统（theme/）

### 文件

| 文件 | 说明 |
| --- | --- |
| `theme_controller.dart` | `ThemeController`：主题模式（system/light/dark）+ 主题配置流 |
| `theme_data_builder.dart` | 从配置构建 `ThemeData`（Material 3） |
| `theme_utils.dart` | 工具函数 |
| `app_theme_config.dart` | `AppThemeMode` 枚举与 `AppThemeConfig` |

### 能力

- `AppThemeMode.system/light/dark` 切换，支持循环切换（`toggle`）。
- 自定义主色（首页"我的"提供 6 色快捷选择）。
- Android 12+ 动态取色（dynamic_color 包）由 `theme_data_builder` 集成。

### 持久化

通过 `ThemeConfigProvider` 写入 ConfigManager；启动时 `ThemeController` 加载恢复。
