# 核心模块：模块化框架

> 开发 Wiki 第八篇 · ModuleManager、动态代理与热插拔

## 1. 设计目标

参考 **Java 动态代理**（Proxy + InvocationHandler）思想，结合 Dart 特性实现模块化：

- **不直接调用模块组件功能**：调用方只依赖服务接口，通过 [ModuleManager] 获取实现（编译期绑定）或 [DynamicProxy] 动态代理转发。
- **热插拔**：模块上线注册到 ModuleManager，下线移除；配置（ConfigModule）、Agent 工具、服务接口三合一联动。
- **性能几乎 0 损耗**：主路径为编译期接口调用（一次 O(1) Map 查找后缓存引用），动态代理仅用于需要运行期拦截/延迟绑定的场景。

## 2. 模块结构

```
lib/core/module/
├── module.dart              # 模块化框架统一出口（export）
├── module_base.dart         # AppModule 抽象 + ModuleContext（生命周期钩子）
├── module_manager.dart      # ModuleManager 注册中心
├── module_event.dart        # 模块上下线事件（ModuleEvent/ModuleLifecycle）
├── module_proxy.dart        # DynamicProxy 动态代理层
├── app_modules.dart         # 9 个内置业务模块（CoreModules.registerAll）
└── interfaces/              # 服务接口（service_interfaces.dart，9 个接口）
```

## 3. 核心 API

### AppModule（模块抽象）

```dart
abstract class AppModule {
  String get moduleName;          // 模块名（唯一）
  int get priority => 100;        // 加载优先级（小者先）
  Future<void> onRegister(ModuleContext context);    // 上线钩子
  Future<void> onUnregister(ModuleContext context);  // 下线钩子
}
```

### ModuleContext（联动能力）

```dart
class ModuleContext {
  ConfigService? config;                 // 配置注册（ConfigModule 上下线）
  void Function(List tools)? registerAgentTools;     // Agent 工具上线
  void Function(List names)? unregisterAgentTools;   // Agent 工具下线
  void Function(Type, Object)? bindService;          // 服务接口绑定
  void Function(Type)? unbindService;                // 服务接口解绑
}
```

### ModuleManager（注册中心）

```dart
Future<void> registerModule(AppModule m);   // 上线（幂等：同名先下线再上线）
Future<void> unregisterModule(String name); // 下线
T? get<T>();                // 获取服务实现（未注册返回 null）—— 0 损耗主路径
T require<T>();             // 未注册抛 StateError
void bind<T>(T impl) / unbind<T>();   // 泛型绑定
void bindByType(Type, Object) / unbindByType(Type); // 运行时类型绑定
Stream<ModuleEvent> get onChange;      // 上下线事件（热插拔感知）
```

### DynamicProxy（动态代理，可选）

Dart 无反射（dart:mirrors 在 Flutter 不可用）且无法 `implements T`（泛型参数），
因此动态代理采用"代理基类 + 方法处理器注册"模式：

```dart
class AppStoreProxy extends DynamicProxy implements IAppStore {
  AppStoreProxy(super.resolver) {
    register('search', (String kw) => resolveT<IAppStore>().search(kw));
  }
}
```

- `noSuchMethod` 拦截全部接口方法调用，从处理器表查找并通过 `Function.apply` 转发。
- `resolveT<T>()` 每次调用实时解析当前实现（模块热插拔自动跟随），支持 `fallback` 降级。
- 适合：AOP 拦截（日志/鉴权/埋点）、延迟绑定、对未上线模块提供降级行为。

## 6. Agent 工具模块化

每个 Agent 工具独立为 `AgentToolModule`（lib/core/agent/）：

```dart
abstract class AgentToolModule extends AppModule {
  String get toolName;              // searchApp / downloadApp ...
  String get toolDescription;       // 模型理解用途
  List<AgentToolParam> get toolParams;
  bool get enabled => true;
  Future<String> execute(AgentToolContext context, Map params);
}
```

- 15 个内置工具在 `tools/builtin_tools.dart`（`BuiltinAgentTools.all`）。
- AgentService 新增 `registerAgentTools/unregisterAgentTools/registeredToolNames`：
  - 初始化时从 ModuleManager 拉取 `AgentToolsModule.tools`（工具上线）
  - `_defineTools`/`buildActions`/chat `toolNames` 动态枚举已注册工具（工具下线即从模型可调用清单移除）
- 模块化工具（未硬编码）自动生成 defineTool + AiAction（参数来自 toolParams）。

## 7. 配置上下线联动

模块上线时通过 `context.config.registerModule(ConfigModule)` 注册配置，
下线时 `unregisterModule` 注销——Agent 的 `configManager list` 自动反映可用配置项。

## 8. 启动流程（main.dart）

```dart
Future<void> _initModuleManager() async {
  final manager = ModuleManager.instance;
  manager.injectContext(ModuleContext(
    config: ConfigService.instance,
    bindService: (type, impl) => manager.bindByType(type, impl),
    unbindService: (type) => manager.unbindByType(type),
  ));
  await CoreModules.registerAll(manager);
}
```

## 9. 性能说明

- **主路径**：`ModuleManager.get<T>()` 是 O(1) Map 查找；调用方初始化时取一次引用，
  后续方法调用为编译期绑定（0 损耗），与直接持有实例无差异。
- **热插拔**：上下线通过 `onChange` 事件通知；引用方重新 `get<T>()` 或改用 DynamicProxy。
- **DynamicProxy**：每次调用有一次 Map 查找 + 动态转发（ns 级），仅限需要拦截/延迟绑定的场景。

## 10. 新增一个模块（示例）

```dart
class MyFeatureModule extends AppModule {
  String get moduleName => 'my_feature';
  Future<void> onRegister(ModuleContext context) async {
    context.config?.registerModule(MyFeatureConfigModule());   // 配置上线
    context.registerAgentTools?.call([MyFeatureTool()]);        // Agent 工具上线
    context.bindService?.call(IMyFeatureService, MyFeatureService()); // 服务绑定
  }
  Future<void> onUnregister(ModuleContext context) async {
    context.config?.unregisterModule('my_feature_config');      // 配置下线
    context.unregisterAgentTools?.call(['myFeatureTool']);      // 工具下线
    context.unbindService?.call(IMyFeatureService);             // 服务解绑
  }
}
// 初始化时：
await ModuleManager.instance.registerModule(MyFeatureModule());
```
