# 快速开始

> 使用 Wiki 第一篇 · 下载安装与第一个应用

## 1. 什么是 GStore

GStore 是一个**基于开源数据的软件商店**，为 Android 用户提供安全、可审计的应用发现、下载、更新与备份。所有应用数据均来自开源仓库，任何人都可以查看与审计。

**核心亮点：**

- 多渠道聚合：GitHub、F-Droid、vivo 应用市场、自定义 API 统一接入
- 开源优先：优先推荐开源应用，标注来源渠道
- 静默安装：Shizuku 授权后免确认安装
- 备份与云同步：本地 / WebDAV 双向备份
- AI 助手：内置 Agent，自然语言搜索、下载、管理应用

## 2. 下载安装

### 方式一：GitHub Releases

从 [GitHub Releases](https://github.com/sunO2/GStore/releases) 下载最新 APK 安装。

### 方式二：本地构建

参考《开发 Wiki · 构建与测试》，或直接使用已有构建产物。

> 提示：Android 12+ 支持 Material You 动态配色，会跟随系统取色。

## 3. 第一次启动

1. 打开 App，进入首页（发现页）。
2. 若列表为空，可下拉刷新或进入「设置 → 数据源更新」拉取最新数据。
3. 在顶部搜索框输入关键词（如 `termux`、`截图`），即可搜索全渠道应用。

## 4. 界面导航

| 区域 | 功能 |
| --- | --- |
| 首页-发现 | 推荐、分类浏览 |
| 首页-应用列表 | 全量应用（可筛选渠道） |
| 首页-我的 | 我的应用、AI 助手、已安装应用、设置、备份、日志 |
| 底部/顶部搜索 | 全渠道搜索 |

## 5. 推荐配置（可选）

- **设置 GitHub 代理**：网络不佳时，在设置中配置代理前缀，加速 GitHub 下载。
- **授权 Shizuku**：安装 Shizuku 并授权后，可实现静默安装与卸载、清理。
- **配置 WebDAV**：有网盘时配置 WebDAV，实现云端备份。

## 6. 遇到问题？

- 查看「设置 → 日志查看器」获取运行日志。
- 应用内 AI 助手也可帮助排查。
- 在 GitHub Issues 提交问题（附上日志）。
