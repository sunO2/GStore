# F-Droid 仓库使用

> 使用 Wiki 第七篇 · 仓库管理、加载索引、搜索 F-Droid 应用

## 1. 什么是 F-Droid 渠道

F-Droid 是知名的开源 Android 应用市场。GStore 将其作为一个**数据渠道**接入：

- 本地解析 index-v2 索引，支持离线搜索。
- 支持增量更新（RFC 7386 merge patch），减少流量。
- 支持自定义源与国内镜像。

## 2. 进入 F-Droid 仓库管理

入口：首页「我的 → F-Droid 仓库」（路由 `/GStore/fdroidRepo`）。

## 3. 仓库管理页功能

### 当前源

- 显示当前使用的源名称与仓库地址。
- 有更新时显示"有更新"徽标。

### 统计信息

- 应用总数、包总数（来自本地索引数据库）。

### 操作按钮

| 按钮 | 说明 |
| --- | --- |
| 加载/重新加载数据 | 下载并解析最新索引（支持增量） |
| 清空数据 | 清空本地索引（需确认） |

### 可用源

| 源 | 说明 |
| --- | --- |
| F-Droid Official | 官方源（含清华、FAU 等镜像） |
| Tsinghua Mirror | 清华镜像（国内推荐，优先级更高） |
| 自定义源 | 点击 `+` 添加自定义仓库地址 |

点击源可切换当前使用。

### 搜索 F-Droid 应用

点击搜索图标，输入应用名称或包名，返回本地索引中的匹配结果；点击结果进入应用详情。

## 4. 通过 AI 助手使用

也可以直接对 AI 助手说：

- "加载 F-Droid 仓库"
- "在 F-Droid 搜索 XX"
- "F-Droid 里有什么应用"

助手会自动调用 `fdroidRepo` 工具执行。

## 5. 使用建议

- **首次使用**：先加载一次索引（国内网络推荐切换到清华镜像）。
- **增量更新**：之后每次加载只下载增量，节省流量。
- **搜索优先**：本地索引搜索比在线搜索更快、可离线。
