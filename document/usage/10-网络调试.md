# 网络调试

> 使用 Wiki 第十篇 · 代理内核、抓包与流量分析

「网络调试」是代理内核（`gstore_mod_proxy` + VPN）的用户界面：连接 / 断开隧道、查看实时
流量与活动连接、抓包与改写、订阅与节点管理、弱网模拟，以及诊断工具。

入口：首页「我的 → 工具 → 网络调试」（路由 `/GStore/proxy`）。

> 底层能力、契约与限制以《代理内核与 VPN》开发文档与 `rust/gstore_mod_proxy/API.md`
> 为准。本文只讲界面怎么用，以及哪些能力**尚未实现**。

## 1. 首页总览

- **连接开关 / 状态**：连接、断开 VPN 隧道；显示运行模式、路由模式、当前节点与延迟。
- **实时流量**：上下行速率与累计量。
- **快捷入口**：
  - **请求域名 / IP**：实时收集的请求列表（抓包列表）。
  - **流量统计**：按域名的连接数与流量。
  - **活动连接**：当前活动连接数，点进去可断开。
- **抓包开关**：总开关；开启前需满足 CA 门控（见 §6、§11）。
- **入口**：订阅、节点选择、抓包设置、代理设置（含弱网模拟）、诊断与日志。

## 2. 连接与实时连接

- **活动连接页**：展示 `conn.list` 的活动连接，支持分页、按域名 / 出站筛选；可**单条断开**
  或**全部断开**（危险确认）。
- 计数如实展示为「共 N 个活动连接 · 已加载 M」，其中 N 来自引擎的连接表快照；
  **列表是分页加载的**，不要把它当作一次性全量。
- 连接表、容量截断与排序都在引擎侧完成，界面只按字段展示，不做聚合或重排。

## 3. 请求域名 / IP（抓包列表）

抓包列表按「已加载 / 保留（retained）」展示记录，支持：

- **分页**：「加载更多」按游标追加，按 `recordId` 去重，游标耗尽即停止。
- **筛选 / 搜索**：按域名、网络类型、协议、HTTP 状态段、方法过滤；筛选变化会本地重算并
  best-effort 转发给后端。
- **排序**：稳定排序（相等键保持原相对顺序）。
- **长按操作**：复制域名、复制 URL、分享（复制可分享的文本摘要）、删除该条记录。
- **导出**：导出 CSV / JSON（可同时导出两种）；导出内容遵循当前筛选。
- **详情**：点击进入抓包详情（§4）。

> **计数口径诚实说明**：契约没有提供「真实总数」字段，界面展示的是**当前已加载 / 保留
> 条数**，不代表全部抓包总量。

## 4. 抓包详情

- **Body 视图**：原始 / 格式化 / **十六进制**；`image/*` 额外渲染**图片预览**（解码失败
  降级为占位，不崩）。
- **按 `Content-Encoding` 解码**展示（gzip / deflate；未知编码回退原始字节），并显示解码
  后字节数与实际应用的编码名。
- **存盘**：正文 / 请求 / 响应以**原始抓包字节**另存（byte-identical，不做重编码）。
- **复制 cURL**：把该请求导出为可复制的 cURL 命令。
- **保存 / 重发到请求调试**：映射成一条可编辑请求写入「抓包」集合，或直接载入编辑器。
- **创建改写规则**：跳转到请求调试的「改写规则」分区并预填。
- **导出为 HAR**：把当前抓包编码为标准 HAR 1.2 并另存（纯 Dart 拼装，不重复请求树）。
- **时间线瀑布**：用可用字段（开始 / 结束 / 耗时）画一条占比条。

## 5. 抓包设置

- **域名白名单**（主门控）：增删、**批量粘贴 / 导入**（解析 + 去重 + 上限校验）、
  **导出**（换行分隔文本到剪贴板）。命中 SNI / host 的主机才解密；白名单为空时退化为
  App 白名单。
- **App 白名单**：多选（按包名，best-effort）。仅在域名白名单为空时生效。
- **内容开关**：抓取请求 / 响应体（Body）、WebSocket（WS）、HTTP/2（H2）。
- **`maxBodyBytes`**：落盘 Body 上限，可编辑（非法值被拦，绝不把坏值下发）。
- **`tlsPorts`**：参与 MITM 的目标端口集合，可编辑（解析校验通过才提交）。
- **明文 HTTP**：端口 80 / 8080 / 8880 的明文 HTTP 在开启抓包且命中白名单时同样会被抓取
  （请求 / 响应详情，`scheme=http`），无需 CA；明文不支持 h2c，`tlsPorts` 优先于这些固定端口，
  端口 / 白名单改动只对新连接生效。
- **存储统计**：采用**抓包环**语义展示「保留 / 容量 / 淘汰 / 丢弃」。
- **未保存提示**：有未保存修改时返回会先经统一确认弹层征求「放弃 / 继续编辑」。
- **CA 门控**：未生成 / 未安装证书时，开启抓包会先给出提示（HTTPS 流量不会被解密，
  仅明文 HTTP 会被抓取），可选「继续开启」直接开启（此时首页状态显示「仅 HTTP」），
  或选「去设置」前往证书页。

## 6. 证书管理（CA）

- **生成 / 重置**：`capture.ca.get` 在未生成时返回「未生成」而非错误；`generate` 幂等，
  `reset` 删除材料并立即停止服务旧叶证书。
- **指纹**：展示 SHA-256 指纹，可**一键复制**；可生成**二维码**（仅编码指纹，不含私钥）。
- **安装**：用户证书（无需 root）或系统证书（仅 root）；安装器拉起后仍需你在系统 UI 确认。
- **信任状态探测**（best-effort）：仅展示「已安装到系统证书存储 / 尚未安装 / 当前平台不
  支持检测 / 状态未知」四种之一，**绝不把“无法检测”谎报成“未安装”**。
- **有效期**：契约 `CaptureCaInfo` 目前**无有效期字段**，界面暂不展示（待契约补充）。

## 7. 订阅与节点

- **订阅（网络组）**：
  - 通过 URL / 粘贴文本 / 分享链接（剪贴板）/ 本地文件导入。
  - 单个订阅「更多」菜单：**重命名**（`profile.update`）、**导出 Clash**、**自动更新间隔**
    （`profile.set_schedule`）。
  - **全部更新**：展示被跳过的订阅及原因（`skipped[]`）；不可刷新的来源隐藏 / 禁用刷新。
- **节点选择**：按名称 / 服务器 / 类型 / 端口**搜索过滤**；**收藏置顶**；节点详情（只读
  展示契约已有字段，不支持编辑）；**复制地址**。
  - **单节点测速**：每个节点行自带**单节点测速**按钮，只探测该行，不牵动其它节点。
  - **收藏**：节点行**左滑**露出「收藏 / 取消收藏」操作，收藏后置顶。
  - **批量测速**（「测试全部」）：一批节点在**固定并发窗口**内探测（最多 10 个同时进行），
    并使用比默认更短的**批量超时**，节点多时也能更快出结果。

## 8. 流量统计与 DNS

- **统计**：流量总览（总量 / 速率 / 活动连接 / Top 域名）；域名可**下钻**到按该域名筛选的
  请求列表；复制域名 / 出站；**导出 CSV**；重置统计。
- **DNS**：查看 / 编辑有效配置、清空缓存；近期查询与域名映射**分页展开**（不再硬截断为
  固定条数），展示应答记录，支持复制查询 / 映射。

## 9. 弱网模拟

预设档位之外，支持**完整自定义参数**（上下行独立）：

- 限速（kbps，`0` = 不限速）、延迟、抖动及其分布、丢包率、突发桶（burst）、
  **丢包模型**（`none` / `random` / `gilbertElliot`）、乱序率与乱序窗口、重复、`seed`。
- 展示进程级**运行计数**（整形计数器，只读）。
- 编辑自定义参数时不会把已选的 `gilbertElliot` 模型重置为 `random` / `none`；非法 / 越界
  值被明确拦截。

## 10. 诊断与日志

诊断页把引擎已有的只读 / 诊断能力接出，**不用于正常业务**：

- **Clash 诊断控制器**：`diagnostics.clash_api.start / stop / status`，仅诊断用；状态不含
  任何 secret。
- **日志查看器**：`log.get`（按级别过滤 / 游标分页）、`log.clear`（清空）。
- **规则查看器**：`rules.get` 只读快照；`rules.reload` 重新加载（可粘贴内联 `rules:` 段）。
- **配置生成 / 应用**：`config.generate`（渲染，不触碰运行中引擎）与 `config.apply`
  （热应用）。生成的 Clash YAML 可能含代理凭证，界面**只展示摘要**（hash / 计数 / 警告），
  不渲染正文。

## 11. Android CA 约束

- **抓包解密依赖设备信任抓包根证书**：需先生成 CA，再导出并安装到设备证书存储。
- **无 root 只能安装用户证书**：Android 7+ 默认不信任用户证书的应用无法被解密；
  Android 11+ 可能需按引导到系统「安全设置」手动安装。
- **系统证书仅 root 可用**（Magisk / bind-mount 等）；本仓库真机安装路径的验证状态见
  《代理内核与 VPN》§10。
- **上游证书校验**：默认严格 webpki，会校验真实上游证书；自签名 / 企业中间代理场景可开
  「跳过上游证书校验」，但开启后该段 TLS **只保证机密性、不保证认证性**，可能被二次
  MITM，绝不应在普通公网开启。
- **信任状态是 best-effort 探测**，不会谎报。

## 12. 非 root · pinning · UDP/QUIC 限制

以下限制**必须如实告知用户**，UI 也会诚实提示：

- **非 root 抓不到任意 App**：无 root 只能安装用户证书；Android 7+ 默认不信任用户证书的
  应用（大量第三方 App）无法被解密。**不绕过证书固定（pinning）**。
- **UDP / QUIC 不抓**：只处理 TCP；HTTP/3（QUIC/UDP）流量既不终止也不记录。生产路径的
  请求采集与导出**只承诺 TCP**。
- **明文 HTTP 可抓取（无需 CA）**：抓包开启且命中白名单时，明文 HTTP（端口 80 / 8080 / 8880）
  的请求方法、URL、状态码、请求 / 响应头与正文同样会被采集并在列表 / 详情页展示，`scheme`
  显示为 `http`；此路径**无需 CA（无需安装证书）**（无 CA 时 HTTPS 仍不解密，仅明文 HTTP 被抓取）。
  明文一律按 HTTP/1.1 处理，**不支持 h2c（明文 HTTP/2）**；`tlsPorts` 优先于这些固定明文端口
  （若把 80 加入 `tlsPorts`，该端口按 TLS 处理、明文不再采集）；抓包端口与白名单配置只对**新连接**生效。
- **WebSocket 只抓帧、不支持改写**：WS 帧可捕获展示，规则不改写 WS 帧。
- **跨 tick 短命流不可见**：请求采集是采样差量法（约 500ms 一次对账），两次 tick 之间
  开启又关闭的流不会产生记录（已接受并测试固化的限制）。
- **`skipCertVerify` 默认关**：仅自签名 / 企业中间代理等明确可信的上游才开。

## 13. 未验证与预留能力

- **真机路径 UNVERIFIED**：`VpnService` 生命周期、TUN 数据面吞吐、Private DNS、真机 CA
  安装与信任、`UidResolver` 归属查询等，在无 adb 设备时以 host loopback / socketpair
  harness 覆盖机制，设备侧行为标注 **UNVERIFIED**（详见《代理内核与 VPN》§10）。
- **断点（拦截）尚未实现**：`captures.breakpoint.*`（`get / set / list / resume / cancel`）
  与 `proxy.capture.breakpoint` 事件的**契约草图已冻结且默认关闭**，但 MITM 暂停 / 恢复
  数据面未实现，当前调用返回 `PROXY_CAPTURE_BREAKPOINT_NOT_IMPLEMENTED`。规划见
  `.omo/plans/proxy-breakpoint-dataplane.md`。**不要把它当作可用功能**。
- **规则 `delayMs`**：仅存储、不注入延迟。
- **DNS / 抓包分页**：计数与列表按游标 / 已加载口径展示，不代表全量总量。
