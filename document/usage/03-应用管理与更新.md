# 应用管理与更新

> 使用 Wiki 第三篇 · 我的应用、已安装应用、更新中心

## 1. 我的应用

首页「我的 → 我的应用」维护你的本地应用收藏（聚合列表）：

| 操作 | 说明 |
| --- | --- |
| 添加应用 | 详情页「添加到我的应用」 |
| 移除应用 | 长按或列表管理入口移除（需确认） |
| 按渠道查看 | 通过渠道应用库按渠道分类管理 |
| 离线可用 | 数据存在本地，无网络也可查看 |

## 2. 已安装应用管理

首页「我的 → 已安装应用」可管理设备上实际安装的应用：

> ⚠️ 卸载 / 清理数据 / 清理缓存 / 强制停止为**高风险操作**，会先弹出确认，且大部分需要 **Shizuku 授权**。

| 操作 | 说明 | 依赖 |
| --- | --- | --- |
| 列表 | 查看已安装应用（可搜索过滤） | — |
| 检查 | 查询某应用是否已安装 | — |
| 卸载 | 卸载应用 | Shizuku |
| 清理数据 | 清除应用数据 | Shizuku |
| 清理缓存 | 清除应用缓存 | Shizuku |
| 强制停止 | 停止运行中的应用 | Shizuku |

### 授权 Shizuku

1. 安装 Shizuku 应用并启动。
2. 无线调试方式（Android 11+）或电脑连接授权。
3. 在 GStore 中确认 Shizuku 可用后即可使用高级管理功能。

## 3. 更新中心

首页「我的 → 更新中心」（或路由 `/GStore/updateCenter`）：

- 展示所有"我的应用"中有新版本的应用。
- 显示 **当前版本 → 最新版本**，点击即可下载更新。
- 下载完成后询问是否安装。

### 更新检查逻辑

- 各渠道分别检查（GitHub / F-Droid / vivo / 本地库）。
- 版本比较采用数字分段解析（兼容 `v` 前缀、`beta/alpha` 后缀、多段版本号）。

## 4. 数据源更新

应用列表数据来自开源数据仓库 [GStore-Repositorys](https://github.com/sunO2/GStore-Repositorys)：

- 设置 → 数据源更新：检查并下载最新应用数据（带版本检测）。
- 数据库版本会持久化；更新失败可重试或手动检查网络。

## 5. 小贴士

- 将常用应用加入"我的应用"，更新中心即可一键管理它们。
- 大版本更新建议先查看详情页的更新内容（Release 说明）。
