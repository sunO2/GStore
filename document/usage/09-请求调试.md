# 请求调试

> 使用 Wiki 第九篇 · 抓包联动的 HTTP 调试工具

「请求调试」是一个 Postman 式的原生工具，用来组装、发送、回看 HTTP 请求，并统一管理
抓包产生的改写规则。它与代理内核解耦：既能独立使用，也能接收「抓包」页保存过来的请求。

入口：首页「我的 → 工具 → 请求调试」（路由 `/GStore/requestDebug`）。

## 1. 工作台总览

顶部用分段按钮切换四个分区：

| 分区 | 作用 |
| --- | --- |
| 集合 | 收藏与组织请求（文件夹树 + 请求列表） |
| 历史 | 每次发送的记录，可回看、重发、保存 |
| 环境 | 环境变量表，供 `{{变量名}}` 替换 |
| 改写规则 | 管理代理引擎的实时响应改写规则 |

集合、历史与环境持久化在应用文档目录的 `request_debug_store.json` 中（历史有上限，超出后
自动淘汰最旧的记录，不会无限增长）；改写规则由代理引擎侧持久化并生效（`capture.rules.*`）。

## 2. 集合：组织你的请求

- **文件夹树**：支持嵌套子文件夹，可展开 / 折叠。
- **新建**：用 `+` 新建集合或子文件夹。
- **导入 cURL**：把一段 cURL 命令粘贴进来，自动解析成一条请求。
- **打开请求**：点击请求进入全屏编辑器。
- **重命名 / 删除**：在集合或请求上操作；删除会二次确认。

## 3. 编辑器：组装请求

进入编辑器后可设置请求名称、方法与 URL，并在以下分段间切换：

| 分段 | 内容 |
| --- | --- |
| 参数 | URL 查询参数（键 / 值） |
| 头 | 请求头（键 / 值） |
| 体 | 请求体文本 |
| 认证 | 认证类型与注入位置（Header / Query） |
| Cookie | 请求 Cookie |
| 响应 | 发送后的响应查看器 |

编辑器支持：

- **发送**：立即发出请求并切到「响应」分段查看结果。
- **保存 / 另存为**：写入当前集合；另存为会克隆成一条新请求（换新 id，不覆盖同名请求）。
- **导出 cURL**：把当前请求导出为可复制的 cURL 命令。
- **插入环境变量**：从当前环境选择变量，插入 `{{变量名}}`，发送时自动替换。

## 4. 响应查看器

发送后展示状态码、耗时与大小，并提供以下视图：

- **格式化 / 原始**切换，以及**复制**。
- 分段：**头 / Body / Cookie / 原始**。
- Body 按 `Content-Type` 渲染 JSON / XML / HTML / 文本；二进制等非文本用安全占位，
  不渲染原始字节；大 Body 分块加载，避免卡顿。
- **保存为改写响应**：把当前响应内容直接带进改写规则编辑器。

## 5. 历史：回看与重发

- 列表展示方法、URL、状态、耗时与时间。
- **重发**：真正再次发送（会先做环境变量替换），并追加一条新历史。
- **保存到集合**：克隆为新请求写入目标集合。
- **删除 / 清空**：危险操作二次确认。
- 点击历史行可载入编辑器继续编辑。

## 6. 环境：变量替换

- 维护多个环境，每个环境是一组键 / 值。
- 点左侧图标把某个环境设为**当前环境**；`{{变量名}}` 按当前环境取值。
- 支持新建、编辑、删除环境（删除二次确认）。
- 变量替换同样作用于 URL、头、体与认证字段。

## 7. 改写规则：联动代理引擎

改写规则是**代理引擎的全局能力**，只对 h1/h2 的 HTTP 请求生效，规则默认**关闭**。
在这里新建 / 编辑 / 开关 / 删除规则：

- **精确 URL**（可再加一个可选的方法过滤）命中才生效。
- **类型**：
  - `替换响应`：正常请求上游，然后用规则里的状态 / 头 / Body 覆盖响应。
  - `返回本地响应`：不请求上游，直接返回规则里的响应。
- 命中次数会累计展示。
- 删除经二次确认。

> 规则要真正生效，需要代理引擎**开启抓包（MITM）**且目标域名命中白名单；同时规则本身
> 必须处于**启用**状态。详见《代理内核与 VPN》的「MITM / 抓包 / 改写」一节。

**WebSocket 不支持改写**：WS 帧只能被抓包捕获查看，规则不会改写 WS 帧。

## 8. 与「抓包」联动

在「网络调试」页开启抓包后：

1. 打开「请求域名 / IP」列表，进入某条请求的**抓包详情**。
2. 详情页提供两个动作：
   - **保存到请求调试**：把该请求映射成一条可编辑的请求，写入名为「抓包」的集合
     （集合不存在时自动创建）。
   - **创建改写规则**：跳转到本工作台的「改写规则」分区并预填内容。

## 9. 限制与注意事项

- **非 root 抓不到任意 App**：HTTPS 解密依赖设备信任抓包根证书；无 root 只能安装**用户
  证书**，Android 7+ 默认不信任用户证书的应用无法被解密。工具不会绕过证书固定（pinning）。
- **UDP / QUIC 不抓**：只捕获 TCP；HTTP/3（QUIC/UDP）流量既不终止也不记录。
- **WS 只抓帧、不支持改写**。
- **发送走应用默认网络**：请求调试发出的请求跟随应用默认网络路径，不保证经代理隧道。
- Cookie jar 为**会话内**：应用重启后不保留。

安装与信任抓包证书的步骤见「网络调试 → 抓包设置 → 证书管理」。
