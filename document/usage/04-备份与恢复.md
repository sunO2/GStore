# 备份与恢复

> 使用 Wiki 第四篇 · 本地备份、WebDAV 云备份与恢复

## 1. 备份内容

GStore 备份可包含：

- **我的应用**（聚合数据库：应用、图标、描述、分类、排序、启用状态）
- **渠道应用库**（各渠道下已添加的应用）
- **应用配置**（主题、下载等设置，可选项）
- **扩展数据**（F-Droid 源列表、Agent 配置等）

## 2. 本地备份

入口：首页「我的 → 备份管理」（路由 `/GStore/backup`）。

### 导出

1. 点击「导出备份」。
2. 选择是否包含应用配置。
3. 备份文件保存到应用文档目录（文件名形如 `gstore_backup_2026-08-10T10-30-00.tar.gz`）。

### 导入 / 恢复

1. 点击「导入」并选择备份文件（或选择已有备份文件）。
2. 选择导入模式：
   - **合并**：与现有数据合并。
   - **替换**：覆盖现有数据。
3. ⚠️ 恢复会**覆盖现有数据**，操作前会再次确认。

### 管理备份文件

- 备份管理页可列出所有备份文件、查看统计、删除旧备份。

## 3. WebDAV 云备份

### 配置 WebDAV

1. 入口：首页「我的 → WebDAV 配置」（路由 `/GStore/webdavConfig`）。
2. 填写：服务器地址、用户名、密码、备份路径（默认 `/GStore`）。
3. 保存并测试连接。

> 凭据保存在系统安全存储（flutter_secure_storage）中。

### 上传备份

- 备份管理 →「上传到 WebDAV」：将当前数据打包为 tar.gz 上传到云端目录。
- 文件名自动带时间戳：`gstore_backup_<时间戳>.tar.gz`。

### 查看云端备份

- 可**查询云端备份列表**（文件、大小、时间），再决定恢复哪个备份。

### 从云端恢复

1. 备份管理 →「从 WebDAV 恢复」。
2. 选择云端备份文件（或自动选最新）。
3. 确认后下载并导入（同样可选择是否恢复应用配置）。

### 支持说明

- 支持 429 限流自动重试、断点（无）、目录自动创建。
- 兼容大多数支持 WebDAV 的服务（Nextcloud、坚果云、WebDAV Server 等）。

## 4. 安全提示

- **恢复会覆盖数据**：务必先确认备份是最新的、内容正确。
- 备份文件内含你的应用列表，请注意保管（上传到网盘前确认信任该网盘）。
- 跨版本恢复时，旧格式（v1.0）备份会自动兼容读取。

## 5. 常见问题

| 问题 | 处理 |
| --- | --- |
| 未配置 WebDAV | 先到 WebDAV 配置页填写并测试连接 |
| 上传失败 | 检查网络/服务器/路径权限；429 已自动重试 |
| 恢复失败 | 检查存储权限、文件路径；确认备份文件完整 |
| 找不到备份 | 确认云端备份目录与配置的 backupPath 一致 |
