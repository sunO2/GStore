# 搜索与下载应用

> 使用 Wiki 第二篇 · 发现应用、查看详情、下载安装

## 1. 搜索应用

### 全局搜索

- 首页顶部搜索框输入关键词（应用名、包名、描述均可）。
- 搜索会**聚合多个渠道**的结果：GitHub、F-Droid、vivo、本地数据库、自定义 API。

### 结果中的渠道标识

每个结果会标注来源渠道，建议优先选择：

- **GitHub**（开源仓库，可审计源码）
- **F-Droid**（开源应用市场）
- **vivo**（热门应用，部分非开源）

## 2. 应用详情页

点击搜索结果进入详情页，可以看到：

| 区块 | 内容 |
| --- | --- |
| 基础信息 | 名称、图标、版本、开发者 |
| 统计标签 | GitHub 星标/关注/分支，应用商店下载量/评分/收藏 |
| 详情区域 | 简介、截图（可放大预览）、版本记录 |
| 下载区 | 下载按钮、APK 大小、架构适配 |

### 下载按钮行为

- GitHub 渠道：**自动匹配设备 CPU 架构**选择对应 APK。
- 大文件：自动启用**多段下载**（并发 + 断点续传），进度更稳。

## 3. 下载中心

通过首页「我的 → 下载中心」进入，可管理所有下载任务：

| 操作 | 说明 |
| --- | --- |
| 查看列表 | 下载中/已完成/失败任务，含进度与速度 |
| 暂停 / 继续 | 支持断点续传 |
| 清理已完成 | 移除已完成任务记录 |
| 清空列表 | 删除全部记录（需确认） |

## 4. 安装应用

下载完成后：

1. 点击安装按钮，或到下载中心点击已完成的任务。
2. 若已授权 **Shizuku**：静默安装，无需系统弹窗。
3. 未授权：回退系统安装器，按系统提示操作。

## 5. 添加到"我的应用"

- 详情页或搜索结果可将应用**添加到我的应用**（本地收藏夹），便于离线管理与统一更新。
- 也可添加到指定渠道（渠道应用库）。

## 6. 常见问题

| 问题 | 处理 |
| --- | --- |
| 下载慢 | 在设置中配置 GitHub 代理前缀 |
| 下载失败 | 检查网络；换渠道（GitHub→F-Droid）；重试 |
| 下载后安装失败 | 检查 APK 完整性，或到下载中心手动安装 |
| 搜索无结果 | 换关键词；检查网络/渠道是否可用 |
