# AI 助手使用指南

> 使用 Wiki 第五篇 · 模型配置、对话、工具能力

## 1. 进入 AI 助手

首页「我的 → AI 助手」（路由 `/GStore/agent`）。

> 首次使用需先在「模型设置」中配置 LLM 模型（否则助手会提示先配置）。

## 2. 配置模型

入口：AI 助手页 → 模型设置（路由 `/GStore/agentSettings`）。

### 支持的类型

| Provider | 说明 |
| --- | --- |
| Google Gemini | 默认模型 gemini-2.0-flash，无需 BaseURL |
| OpenAI 兼容 | gpt-4o-mini 等，可自定义 BaseURL（支持代理/中转服务） |

### 配置项

- 名称（自定义别名）
- Provider 类型
- API Key
- 模型名（留空用默认）
- Base URL（OpenAI 兼容服务可填中转地址）

支持多模型配置，可随时切换当前使用的模型。

## 3. 对话界面

- **消息时间轴**：同一回合的助手回复与工具调用按执行顺序竖向展示。
- **工具胶囊**：每次工具调用显示为胶囊（如"搜索应用"、"下载应用"），点击可查看调用详情（可复制）。
- **确认节点**：涉及敏感操作时，助手会**内联展示确认按钮**，确认后才执行。
- **流式输出**：回复逐字流式显示（Markdown 渲染）。
- **停止生成**：点击停止按钮可中断，保留已输出内容。

## 4. 助手能做什么

直接输入自然语言即可，例如：

| 你想做的事 | 可以这样问 |
| --- | --- |
| 找应用 | "帮我找一个截图工具" / "推荐一个终端应用" |
| 下载安装 | "下载 Termux" / "安装刚才那个应用" |
| 检查更新 | "检查我的应用是否有更新" |
| 管理我的应用 | "把 XX 加入我的应用" / "我的应用里有什么" |
| 渠道管理 | "把 XX 添加到 GitHub 渠道" / "渠道里有哪些应用" |
| 备份 | "备份我的数据" / "恢复到昨天" |
| 下载管理 | "下载列表有什么" / "暂停 XX 下载" |
| 主题 | "切换深色模式" |
| F-Droid | "加载 F-Droid 仓库" / "在 F-Droid 搜 XX" |
| WebDAV | "网盘里有哪些备份" / "上传备份到网盘" |
| 已安装应用 | "我装了什么应用" / "XX 装了吗" |

### 助手的工作方式

助手会调用内置工具执行实际操作（搜索、下载、安装、备份等），并在执行**敏感操作前要求你确认**：

- 卸载应用、清理数据/缓存、强制停止
- 恢复备份 / 覆盖数据
- 删除会话 / 清空下载记录
- 从"我的应用"或渠道移除应用

遇到多选场景（如"用哪个版本"），助手会给出**选项按钮**让你点选。

## 5. 对话历史

- 多会话管理，历史自动保存。
- 历史按"完整回合"加载，向上滚动可加载更早的对话。

## 6. 推荐策略说明

助手默认**优先推荐开源应用**（GitHub、F-Droid 渠道），并标注来源；开源无合适选择时才推荐 vivo 热门应用。

## 7. 常见问题

| 问题 | 处理 |
| --- | --- |
| 提示未配置模型 | 到模型设置填写 API Key 等 |
| 请求失败 | 检查 API Key、网络；OpenAI 兼容服务检查 BaseURL；可换模型 |
| 下载失败 | 参考助手给出的原因建议；换渠道或重试 |
| 助手无法操作某功能 | 告知其能力边界，可到对应页面手动操作 |
