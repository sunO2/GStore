# 常见问题

> 使用 Wiki 第八篇 · 问题排查与解答

## 1. 安装与启动

### Q: APK 安装失败 / 提示解析错误

- 确认 APK 已完整下载（对比下载中心文件大小）。
- 到下载中心重新下载后再试。
- 检查设备存储空间。

### Q: 安装时提示"未知来源"

- 在系统设置中允许"安装未知来源应用"。
- 或授权 Shizuku 后使用静默安装。

## 2. 搜索与数据

### Q: 搜索无结果

- 换更短/更通用的关键词。
- 检查网络是否可用。
- 尝试"数据源更新"拉取最新应用数据。
- 部分渠道（GitHub）需要网络；本地数据库渠道离线可用。

### Q: 应用列表为空

- 下拉刷新。
- 设置 → 数据源更新，检查是否有新数据。

### Q: 更新数据失败

- 检查网络与代理配置。
- GitHub 相关请求失败时可配置/更换代理前缀。

## 3. 下载

### Q: 下载很慢

- 配置 GitHub 代理前缀（设置页）。
- 大文件建议保持前台或使用通知栏进度。
- 换渠道下载（如 GitHub → F-Droid）。

### Q: 下载失败 / 下载地址失效

- 提示可能原因：网络、URL 失效、服务器不支持断点续传。
- 建议重试或换渠道；GitHub 可尝试更换代理。

### Q: 下载到一半失败

- 支持断点续传，直接重新下载会自动续传（服务端支持 Range 时）。
- 持续失败请检查网络稳定性。

## 4. 安装与卸载

### Q: 卸载/清理应用提示需要授权

- 这些功能需要 **Shizuku** 授权。
- 安装并启动 Shizuku（无线调试方式或 USB 连接电脑授权），再重试。

### Q: 下载成功但安装失败

- 检查 APK 完整性（可能下载损坏）。
- 到下载中心手动安装。
- 确认系统允许安装未知来源。

## 5. 备份与恢复

### Q: WebDAV 上传/下载失败

- 确认已在 WebDAV 配置页填写并测试连接成功。
- 检查网络、服务器地址、备份路径权限。
- 云端 429 限流会自动重试（2s/4s/6s）。

### Q: 恢复时提示"找不到备份"

- 确认云端备份目录与配置的备份路径一致。
- 本地恢复请确认备份文件存在且未损坏。

### Q: 备份恢复后应用不见了

- 恢复会**覆盖现有数据**；请确认选择的备份是期望的版本。
- 旧格式（v1.0）备份自动兼容，但只含聚合库数据。

## 6. AI 助手

### Q: 提示"请先配置 LLM 模型"

- 进入 AI 助手 → 模型设置，填写 API Key（Google Gemini 或 OpenAI 兼容）。

### Q: 请求失败

- 检查 API Key 是否正确、账户是否可用。
- 检查网络；OpenAI 兼容服务检查 BaseURL 是否正确。
- 尝试切换其他已配置的模型。

### Q: 助手执行了危险操作？

- 助手对敏感操作（卸载、清数据、恢复备份、删除等）**必定先弹确认**，未确认不会执行。
- 若误操作，可尝试备份恢复。

### Q: 助手说"无法获取 XX 应用信息"

- vivo 渠道缺少应用标识时需网络搜索解析；失败可稍后重试或到详情页查看。

## 7. 其他

### Q: 如何反馈问题 / 提交日志

- 「我的 → 日志查看器」查看运行日志。
- 到 [GitHub Issues](https://github.com/sunO2/GStore/issues) 提交，附上日志与复现步骤。

### Q: 如何贡献应用数据

- 前往 [GStore-Repositorys](https://github.com/sunO2/GStore-Repositorys)，按数据规范提交 PR。

### Q: F-Droid 加载失败

- 切换到清华镜像源再加载。
- 检查网络；增量更新失败时可强制刷新（重新加载数据）。
