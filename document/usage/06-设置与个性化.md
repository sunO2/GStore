# 设置与个性化

> 使用 Wiki 第六篇 · 设置、主题、代理与日志

## 1. 设置页

首页「我的 → 设置」（路由 `/GStore/settings`）。

### 数据源更新

- 检查并下载最新应用数据（来自开源仓库 GStore-Repositorys）。
- 带版本检测，仅在有新版本时提示更新。

### GitHub 代理

- 可配置 GitHub 代理前缀（默认 `https://gh-proxy.org/`）。
- 留空表示不使用代理。
- 改善 GitHub 相关请求（搜索、Release 下载、图片加载）的网络体验。

> 适用场景：下载慢/超时、图片加载失败、搜索无结果时尝试配置或更换代理。

### 日志查看器

入口：首页「我的 → 日志查看器」（路由 `/GStore/logViewer`）。

- 实时查看应用运行日志（所有 debugPrint 已重定向至此）。
- 排查问题、反馈 Bug 时提供日志会很有帮助。

## 2. 主题设置

首页「我的 → 主题设置」（路由 `/GStore/themeSettings`）。

### 主题模式

| 模式 | 说明 |
| --- | --- |
| 跟随系统 | 自动跟随系统亮/暗色（默认） |
| 浅色 | 强制浅色 |
| 深色 | 强制深色 |

### 自定义主色

- 提供 6 种预设主色（蓝、绿、红、橙、紫、青）。
- Android 12+ 可选择**动态取色**（Material You，跟随壁纸）。

### 主题继承

主题选择会持久化保存，重启后保持。

## 3. 已安装应用管理

入口：首页「我的 → 已安装应用」（路由 `/GStore/installedApps`）。

支持卸载/清数据/清缓存/强制停止（需 Shizuku 授权），详见《应用管理与更新》。

## 4. WebDAV 配置

入口：首页「我的 → WebDAV 配置」（路由 `/GStore/webdavConfig`）。

填写服务器地址、用户名、密码、备份路径并测试连接，详见《备份与恢复》。

## 5. 工作流设计器

入口：设置 → 工作流（路由 `/GStore/workflowDesigner`）。

可视化设计数据获取/处理流程：

- 支持 HTTP 请求、数据提取、转换、过滤、排序、去重、延迟等步骤。
- 可绑定渠道函数并配置参数。
- 适合高级用户定制自己的数据源处理逻辑。

## 6. 其他功能

| 功能 | 入口 | 说明 |
| --- | --- | --- |
| F-Droid 仓库 | 设置 / 首页 | 管理 F-Droid 源、加载索引、搜索 |
| 账号 | 首页「我的 → 账号」 | 账号信息页 |
| 关于 | 设置 | 版本信息（当前 1.0.24+1） |
