## Design / data reuse

- Data source = **todo-21** `ChargeHistoryStore`（可注入；生产默认
  `SharedPrefsChargeHistoryStore`）——**无第二 store/引擎**。
- 记录 = `ChargeRecord`（Scene `charge8.records` 列逐字：`time,session,current,
  voltage,capacity,temperature`），派生 `power = current*voltage/1000`（库内 getter）。
- 三图均为**横轴 = 容量 (%)**（Scene 三条查询 `select capacity,<metric>,time ...
  order by time`，见 task-33 `.omo/evidence/task-33-scene-data-schema.md`）：
  1. 电流 `current`（mA）—— `select capacity,current,time`
  2. 温度 `temperature`（℃）—— `select capacity,temperature,time`
  3. 功率 `power = current*voltage/1000` —— `select capacity,(current*voltage/1000),time`
- 会话分组复用 todo-21 `summarizeChargeSessions`；本页新增纯函数
  `chargeCurveSeries(records, session:)` = 按会话过滤 + 按**容量升序**（同容量按时间）
  排序，作为三图样本序。
- 图表复用无第三方依赖的 `LineChart`（`lib/compent/line_chart.dart`，`CustomPainter`
  自绘）——**不加依赖**。
- 约定：颜色一律 `Theme.of(context).colorScheme`（current→primary、
  temperature→tertiary、power→secondary），间距/圆角走 `AppSpacing`；loading 用
  `AppLoading`；无硬编码颜色/字号。

## 口径说明 / 与 plan 命名的对应

- plan 文字记三图为「电流-容量、温度-容量、**时间-容量**」；`task-33` 的第三序列为
  `capacity+power+time`。本页第三图取**功率-容量**（时间用于样本排序），与 todo-33
  的「3 chart series = capacity+temperature / capacity+current / capacity+power」
  （继承自 `task-33`）一致；第三图纵轴单位标 `unverified`（Scene CSV 标 `Power(mW)`
  却对 `mA×V` 再 `/1000`，内部不一致）。
- 空态：无记录时仍渲染**三张空图表**（`LineChart` 空值绘制基线）+ 顶部空提示卡。
