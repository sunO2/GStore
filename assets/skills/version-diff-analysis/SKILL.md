# 版本差异分析

1. 确认目标应用；不确定包名时先调用 `installedApps list` 定位。
2. 调用 `appSnapshot`，`action=list` 查看现有快照；不足两份时先调用 `appSnapshot`，`action=create` 采集当前版本，可添加 `note`。
3. 调用 `snapshotCompare` 比较快照；需要指定两份时传 `oldId` 和 `newId`。
4. 按重要性解读差异：
   - 签名是否变化；变化时必须提醒用户可能被重新签名或来源不同。
   - DEX 和原生库是否变化；据此判断是整体重新构建还是仅资源更新。
   - 新增或移除的权限、新导出的组件和新增深链。
   - 体积变化；直接转述工具给出的增减数值，不要让用户自行计算。
5. 只陈述工具返回的事实，不要臆测差异中没有的改动；待确认项要说明原因。
6. 输出顺序：先给一句话结论，再按分节列出要点。
