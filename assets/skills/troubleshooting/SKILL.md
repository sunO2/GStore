# 问题诊断与失败处理

1. 先向用户说明问题，不要假装成功。
2. 按错误类型处理：
   - 搜索无结果：更换关键词或检查渠道。
   - 下载失败：检查网络、URL 是否失效、服务器是否支持断点续传。
   - 安装失败：检查 APK 完整性，或引导用户从下载中心手动安装。
   - 备份失败：检查存储权限和路径。
   - 模型或 API 失败：检查 API Key、网络和模型配置。
   - 配置失败：调用 `configManager list` 确认可用配置项。
3. 给出可执行的下一步建议。
4. 避免重复无意义重试。
